连接 Outlook
在收件台内收发邮件，需要注册桌面应用并登录授权。Codex 邮箱插件的登录不会自动转移到此应用。
在 Google Cloud 启用 Gmail API，创建“桌面应用”OAuth 客户端，然后导入下载的完整 JSON。只填 Client ID 无法完成 Gmail 授权。
在 Microsoft Entra 注册支持个人/组织账号的桌面应用，添加“移动和桌面应用”重定向 URI：http://localhost/oauth/callback。使用委托权限 User.Read、Mail.Read、Mail.Send。
授权通过系统浏览器完成。令牌使用 Windows 本机加密保存。断开连接会删除本机令牌；如需撤销服务端许可，请到邮箱账号的应用授权管理页面操作。
