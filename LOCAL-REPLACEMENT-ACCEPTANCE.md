# Local replacement acceptance

The Rust core and the pinned Python Hub are separate programs. Validate the
pinned Python source at `c7052745fab3fa1880c6e3a496f40609185668b9` and the
selected Rust commit using separate disposable data directories. Do not point
either candidate at an existing installation, install a startup task, use
live account credentials, or assume a source checkpoint is a release.

## Required local checks

| Area | Evidence required before qualifying it |
| --- | --- |
| Build | Pinned Rust revision, lockfile, compiler, operating system and artifact checksum; failed and unexecuted targets are separate from passing targets. |
| Detached WeChat | Authorize only the exact fixture files; round-trip original public IDs and direction. Preserve display-only reply previews; no inferred quote target from a normal export. Reject wrong account and source bytes before any write. |
| Detached WeCom | Use a first complete synthetic snapshot, then a second with two pages. Stop after page one: inspect old complete display and the exact page receipt. Resume only the exact next page; resolve duplicates and display-only drift without deleting omitted older rows. Verify aggregate counts independently from Python processed-candidate counts. |
| Archive and search | Compare rows and scoped IDs, exact literal behavior and ordering before comparing latency. Wide and one-conversation exports are distinct; do not infer omitted CSV direction. |
| Operator pause | Exercise both admitted-write-first and pause-first orderings on independent local clients. Verify committed rows, exact existing receipts and no new receipt after rejected admission. Separate manual job cancellation from the archive policy. |
| Desktop events | Filter a complete page, save its checkpoint without a visible item, then reconnect and verify only a later eligible item appears. Separately test explicit durable ACK and policy-revision invalidation; these parts do not prove OS delivery. |
| Protected restore | Validate an exact reviewed capsule and publish only to a new directory. Check no-replacement on collision, inspect a known exact receipt when the report is lost, and keep failed parent sync distinct from an unapplied restore. |
| Desktop and MCP | Verify equivalent scope controls for the contracts actually used. Keep ordinary native-live Windows launch/drain, scoped read-only MCP, and the explicit note-only stdio scope separate; no grant can cross into a different mode. |

Do not call an unauthorized provider, test remote sends, or copy a running
profile. Full replacement additionally requires the original client paths and
required live/platform workflows, plus a tested migration and rollback. A
source-only Rust equivalent or safe subset is not a passed legacy route.

Once functionality on a comparison lane is established, run the same
datasets and workload on both backends. Report CPU, resident memory,
throughput and p50/p95 latency with exact versions and scope. Do not reuse a
comparison from a different candidate as a measurement for this release.
